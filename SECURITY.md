# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities through [GitHub's private vulnerability reporting form](https://github.com/kaws26/Parakh-AI/security/advisories/new). Reports submitted there are visible to repository maintainers privately so they can investigate and coordinate a fix.

Include a brief description, affected versions or components, the impact you observed, and safe steps to reproduce the issue. Share only information needed to investigate; do not include credentials, personal data, or production user data.

Please do not report vulnerabilities in public issues, discussions, or pull requests. If private reporting is unavailable, contact the repository maintainers through a verified private channel and do not disclose vulnerability details publicly.

## Supported versions

Security fixes are made against the current `main` branch. Maintainers may also address issues in a recent release when practical.
