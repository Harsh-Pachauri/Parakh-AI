# Frontend

The React and Vite application is part of the AI-Based Viva Voce System. For requirements, environment configuration, setup, available workflows, and API details, see the [repository README](../README.md).

From this directory, use `npm install`, `npm run dev`, and `npm run build`. The development server runs on port 5173 and proxies `/api` requests to the backend at `http://127.0.0.1:8000`.
